# infinitus. lead tracker

A small shared dashboard for two people to track every lead they contact.

- **Sections per business.** Gyms, Real estate and Clinics come pre-created. Add any new business from the sidebar (**+ Add / manage**) and it gets its own section.
- **Lead status.** New, Contacted, Interested, **In trial**, **Booked**, **Closed won**, **Closed lost**. Change it in one click from the lead page. Trial and booking dates and the lost reason are captured, and every change is logged on the lead's timeline.
- **Dashboard.** Counts by status, a card per business, follow-ups due, running trials, bookings.
- **Per lead.** Contact details, who handles it, last contact, next follow-up, deal value, notes, WhatsApp and call links, and a contact log.
- **Lists.** Status tabs, search, filter by business, person or follow-up due, and CSV export.
- Two seats (owner plus partner), sign-in throttling, CSRF protection.

Stack: Django, PostgreSQL on Supabase, Docker on Render Free. No Redis, workers or disk.

## Deploy (Render Free + Supabase)

1. Create a Supabase project. Under **Connect > Session pooler** copy the URI (port 5432), insert your URL-encoded database password and append `?sslmode=require`.
2. Push this repo to GitHub and create a Render **Blueprint** from `render.yaml`.
3. Set `DATABASE_URL` to that URI. `SECRET_KEY` and `SETUP_TOKEN` are generated by Render.
4. Open `https://<your-app>.onrender.com/setup/`, enter `SETUP_TOKEN` (Render > Environment), and create the owner account. Then add your partner under **Team & account**.

The app keeps its tables in a private `infinitus` schema. Do not expose it through Supabase's Data API. All access goes through Django.

Render Free sleeps after inactivity, so the first load after a quiet spell takes about a minute. Data lives in Supabase and is unaffected. Supabase free projects pause after a week of no activity, so open the app at least weekly. Back up with `python scripts/backup.py` (needs `pg_dump`) or the CSV export.

## Run locally

```bash
uv sync
DEBUG=true uv run python manage.py migrate
DEBUG=true uv run python manage.py runserver
```

Open http://localhost:8000/setup/ (no token needed in debug mode). Without `DATABASE_URL` it uses a local SQLite file.

Tests: `DEBUG=true uv run python manage.py test tests --settings=config.test_settings`

Forgot a password: `uv run python manage.py recover_account <username>` (run in the Render shell with `DATABASE_URL` set).
